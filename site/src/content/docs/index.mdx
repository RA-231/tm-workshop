## Dashboards & UIs

Open these in your browser. Each appears once you've started the stack for its
step (`task up:ingest`, `task up:query`, `task up:chat`).

<CardGrid>
  <LinkCard title="Flink" href="http://localhost:8081" description="Job dashboard — watch the ingest job read files and commit Iceberg snapshots. (task up:ingest)" />
  <LinkCard title="Trino" href="http://localhost:8080/ui/" description="Query engine UI — inspect query plans, splits, and bytes read. (task up:query)" />
  <LinkCard title="Superset" href="http://localhost:8088" description="Dashboards and SQL Lab. Log in with admin / admin. (task up:query)" />
  <LinkCard title="LibreChat" href="http://localhost:3080" description="Chat UI wired to the model gateway. Register any account. (task up:chat)" />
</CardGrid>

## APIs & endpoints

Not browser UIs — these are the service endpoints the stack talks to.

<CardGrid>
  <LinkCard title="Polaris" href="http://localhost:8181/api/catalog/v1/config" description="Iceberg REST catalog — the source of truth for what tables exist." />
  <LinkCard title="Garage (S3)" href="http://localhost:3900" description="S3-compatible object store holding the Iceberg warehouse bucket." />
  <LinkCard title="LiteLLM" href="http://localhost:4000" description="OpenAI-compatible gateway in front of the workshop model project. (task up:chat)" />
