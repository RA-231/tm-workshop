## Dashboards & UIs

Open these in your browser. Each appears once you've started the stack for its
step (`task up:ingest`, `task up:query`, `task up:chat`).

<CardGrid>
  <LinkCard title="Flink" href="http://localhost:8081" description="Job dashboard — watch the ingest job read files and commit Iceberg snapshots. (task up:ingest)" />
  <LinkCard title="Trino" href="http://localhost:8080/ui/" description="Query engine UI — inspect query plans, splits, and bytes read. (task up:query)" />
  <LinkCard title="Superset" href="http://localhost:8088" description="Dashboards and SQL Lab. Log in with admin / admin. (task up:query)" />
  <LinkCard title="LibreChat" href="http://localhost:3080" description="Chat UI connected to the model gateway. Create a local account. (task up:chat)" />
</CardGrid>
